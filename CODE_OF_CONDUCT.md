# Code of Conduct

## Our commitment

PHP Gallery is a community project. We want participation to be respectful,
constructive, and welcoming to people with different backgrounds and levels of
experience.

## Expected behavior

- Be considerate and respectful in discussions, issues, reviews, and other
  project spaces.
- Explain disagreements about ideas or code without attacking people.
- Accept constructive feedback and make room for others to participate.
- Share only information that is appropriate for a public project space.

## Unacceptable behavior

- Harassment, discrimination, threats, or personal attacks.
- Insults, sexualized language, or deliberately humiliating remarks.
- Publishing another person's private information without permission.
- Repeated disruption of discussions or other conduct that makes participation
  unsafe or unwelcoming.

## Scope and enforcement

This code applies in the repository, its issue and pull request discussions, and
other project spaces when someone is representing PHP Gallery. Project
maintainers are responsible for clarifying and enforcing these expectations.
They may edit or remove unacceptable contributions and may restrict access for
conduct that continues after intervention.

To report a conduct concern, contact the maintainer privately through the
[GitHub profile](https://github.com/klusik). Do not use a public issue for
private or sensitive details. Reports will be reviewed as promptly as practical
and handled with discretion.

This code is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).
